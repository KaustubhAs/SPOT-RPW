# robust-OT-RPW
Motivation taken from : https://arxiv.org/pdf/2212.08049, code is modified from : https://github.com/nbonneel/spot

Steps to run the FIST and ColorTransfer:
1. Double click on the slice.sln -> It will open the Visual Studios (Not VSCode)
2. Keep the top 2nd row options as "Release" and "x64"
3. Right click on colorTransfer or FIST on the left column and click on build, wait for build sucessful
4. In the cmd run the ".\colorTransfer.exe" or ".\FIST.exe" command to run the respective applications
